NEMA EVENTS — GITHUB PAGES QUICK DEPLOY

1. Extract NEMA_EVENTS_Immersive.zip.
2. Open the nema_github_pages folder.
3. Upload the CONTENTS of that folder to the root of your GitHub Pages repository.
   Make sure index.html, styles.css, app.js, .nojekyll and the assets folder are all uploaded.
4. In GitHub, open Settings > Pages and confirm the published branch and folder.

The project uses relative asset paths and does not require a build step.

Before launch, verify the WhatsApp contact number and all product details. The bag sends product enquiries; it does not accept payments. Newsletter entries are local preview data until a mailing-list service is connected.
